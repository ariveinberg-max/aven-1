# notebooks/

This directory is for exploration and visualization only.

- Outputs are stripped on commit (nbstripout), because outputs can contain data.
- Name notebooks `YYYYMMDD-<initials>-<topic>.ipynb`.
- Code that is reused, or that produces a reported number, moves into `src/neurolayer/` with tests. Numbers in notebooks are never cited as results. Only official runs count (see `docs/results/`).
