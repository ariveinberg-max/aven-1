## The labeling-pool fix, and what it actually revealed
Widened both the AI-judged and human-facing prompt pools today, testing every addition live against the current checkpoint before adding it — same discipline as everything else this project does. But repeated real feedback surfaced something deeper: the actual complaint wasn't prompt repetition, it was response repetition — "Bye" keeps producing "Goodbye! Come back anytime." because that's one of only 4 farewell responses the model was ever trained on. No amount of prompt-pool widening or checkpoint rollback creates a reply that was never in the training data. Expanded the underlying reply-variant lists (farewell, greeting, identity, help, thanks, wellbeing) directly and regenerated the instruction corpus. A first, short fine-tune attempt showed real instability at the sampling temperature used for labeling; a longer run is in progress, and won't be promoted unless it's genuinely clean.
