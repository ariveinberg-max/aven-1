# Build log — Entry 16

A fourth failed attempt at the labeling-diversity problem, and a real change in what "failed" actually means this time.

## Testing a literature-grounded idea, and watching it flip on replication
Yesterday's research explained why factual answers degrade under high sampling temperature more than conversational ones — a well-established mechanism, with a real published technique built around it ("factual-nucleus sampling"). Built a practical version: generate the first few tokens at high temperature (to preserve real response-path diversity), then anneal down for the rest (to reduce mid-generation garbling once a path is chosen).

First test looked promising, if not decisive. Replicated it before trusting that, per this project's own standing rule — and the result flipped completely. Fixed temperature won the second run by the same crude metric that had the decaying approach ahead the first time.

## The metric itself is the real problem
Rather than stop at "inconclusive," inspected the "winning" run's supposedly-clean responses by hand. At least 6 of 13 were actually garbled — missed entirely by the automated check this project has been using throughout this whole investigation. The decaying approach's bucket had comparable hidden garbling too.

That reframes everything. This is now the fourth real attempt at the labeling-diversity/garbling problem — a dictionary-based coherence filter, an adaptive per-prompt temperature schedule, an LLM judge, and now a literature-backed decaying-temperature scheme — and all four have failed. But they haven't failed for four different reasons. The actual common thread: this project doesn't yet have a coherence *measurement* that can reliably tell a clean response from a garbled one. Every fix attempt so far has been evaluated with the same crude, unreliable proxy — so even a genuinely better generation strategy would be invisible to the test being used to judge it.

## What actually changes now
Fixing generation without a trustworthy way to measure whether it worked has failed four times in a row for what looks like the same underlying reason. The real next step isn't a fifth generation-strategy fix — it's building a coherence measurement that can actually be trusted, likely needing either a stronger judge model or a real human-labeled ground-truth set to validate any automated check against, before attempting generation fixes again.

## Dataset
1,427 total comparisons as of today (1,183 human, 244 AI-labeled).
