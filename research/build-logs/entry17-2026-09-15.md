# Build log — Entry 17

A real UI redesign, an honest correction on what "professional software" actually means, and the real cost of yesterday's fix.

## The labeling tool, redesigned
Stripped the labeling interface down from a five-tab dashboard (training, chat, sources, memory, preferences all bundled into one page) to a single, focused preferences tool — nothing else. Every underlying function stayed identical (the same API calls, the same keyboard shortcuts, the same coherence-judge-gated generation), just presented as what it actually is: a dedicated comparison tool, not a general dashboard with preferences bolted on.

## What "real software" actually means here
A real, useful correction came out of discussing whether to replace the custom tool with "the same software OpenAI and Anthropic use." That software doesn't exist for anyone outside those companies — it's private, internal infrastructure, not something available at any price. What *is* real and available is Argilla, an open-source annotation platform genuinely used in the RLHF ecosystem. Also worth correcting directly: "localhost" isn't the thing that makes a tool unprofessional — real labs run internal tools on localhost too. The actual, honest reason to eventually switch isn't the current tool being fake; it's that Argilla becomes worth the real integration cost once there's a second labeler, not before. Added that as an explicit roadmap milestone rather than building it speculatively now.

## The real cost of yesterday's fix
Yesterday's LLM-judge deployment was a genuine, measured improvement — but it has a real, felt cost: pair generation now takes 8-12 seconds instead of being near-instant, since each candidate needs a live judge call. Looked into whether simply parallelizing the two judge calls would fix this for free. It won't, by default: Ollama's own concurrency setting defaults to fully sequential processing, especially on a memory-constrained machine, and even with it explicitly raised, a Mac's shared compute would only give a modest improvement, not a real 2x. This is a structural cost of the fix, not a quick follow-up patch — reported honestly rather than assumed fixable.
