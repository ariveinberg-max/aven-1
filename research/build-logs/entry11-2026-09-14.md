# Build log — Entry 11

Closing out Day 19: a real, measured answer to a question this project has had open since Week 1, and an honest verdict on whether "reasoning models" are within reach at this scale.

## A real answer to the capacity-ceiling question
Since Week 1, this project has had an open, untested hypothesis: does repeated RLHF fine-tuning narrow a small model's usable output space over time, not just its per-prompt response diversity? Today gave a real, measured answer. Comparing the current checkpoint (RAFT-3) against the one from the prior RAFT round (RAFT-2) on the same 9 test prompts, at the same temperatures: RAFT-2 ties noticeably less (3/9 vs. RAFT-3's 4-6/9). Each successive RAFT round is measurably compounding generation collapse — and not just on the specific prompts it trained on, on close paraphrases and unrelated prompts too.

This surfaces a real tradeoff this project hasn't been weighing explicitly: running a new RAFT cycle nearly every training block improves response quality on the targeted prompts, but appears to be actively narrowing the model's coherent output space in ways that then make the labeling pipeline itself worse. Two earlier attempts today (a dictionary-based coherence filter, an adaptive-temperature schedule) both failed to work around this — the real cause isn't a fixable generation parameter, it's the training history itself.

## Reasoning models at this scale: a real, unglamorous verdict
Looked seriously at whether Aven could try a small-scale version of o1/DeepSeek-R1-style reasoning — training the model to "think" before answering. Checked the actual published evidence rather than assuming it would transfer down: DeepSeek-R1's own paper never runs its RL process on small models, choosing distillation instead for anything below frontier scale. TinyZero, a well-known minimal reproduction, tested a 0.5B model — almost exactly Aven-2's size — and found it **fails to learn reasoning** under the same RL process that works at 3B+.

The mechanism explains why plainly: RL only reinforces a correct reasoning trace the model already produces by chance sometimes. A model this small essentially never produces one on its own, so there's nothing for the reward to select for. Genuine RL-discovered reasoning isn't viable here — not a "maybe," a fairly unambiguous negative result. What is testable: distillation from a larger teacher's traces, using infrastructure this project already has. A real, useful negative result, reported plainly instead of chasing a technique that doesn't transfer.
